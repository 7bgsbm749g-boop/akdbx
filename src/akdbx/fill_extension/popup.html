Checking the akdbx broker…

A reset forgets the broker key and keeps the broker address. The extension then accepts a new key only from the broker's HTTPS page at that address. Reset only if you set up this broker again yourself.

First use with this broker. akdbx opens pairing and unlock pages only on a broker address that you confirm. The akdbx native host on this computer names this address:

Confirm it only if it is your broker's address: “akdbx status” on the computer with the broker shows it as extension_trust.origin, and “akdbx setup” prints it. If you do not know this address, do not confirm it and do not enter your master password.

Forgetting deletes the saved broker address and key. akdbx then asks you to confirm the address that the broker names now. Forget only if you moved or set up this broker again yourself.
